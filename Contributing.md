# Want to contribute to Open Circles?

Before going to the specifics, contributions to Open Circles should follow these basic guidelines.

- Each module should have 1 or more clearly stated focus. For example in OC01, the main focus is computer vision. The workshop submodules cover: 
    - What is Computer Vision
    - Introduction to Convolutional Neural Network
    - A Brief History of Convolutional Neural Network
    - Hands-On Session Implementing CNN for Semantic Segmentation
    - Introduction to Attention Mechanism & Transformer Architecture
    - Introduction to Visual Transformers ViT
    - Hands-On Session Implementing SETR for Semantic Segmentation

- Expected materials are:
    - Source code
    - Slides
    - Google Colab Notebook / Jupyter Notebook

- All materials provided should adhere to the following rules:
    - Files pushed to GitHub should not exceed (>3MB). Exceptions are excepted after further discussion.
    - Well documented code, with links to reading materials (research paper, articles, books, videos, etc.)
    - Well formatted code (following standards such as yapf, pep, etc.)
    - Coherent folder structure (folders should be named and separated according to their logical function, type)
    - Code that are generated with AI sould have clear disclaimer.

        ```python
        """
        This function is AI generated.

        OR

        Visualization code was generated with GenAI

        OR

        Code was generated with GenAI, this script is not used in the workshop
        """
        ```

Please check which case you fall under first.

1. Open Circles Official Annual Workshop *i.e. OC01, OC02*. **Refer Section 1**

1. Open source contribution. Refer **Section 2**
